**Anthropic Engineering: Claude Code auto mode — a safer way to skip permissions**

Auto mode is a new Claude Code mode that delegates approvals to model-based classifiers — a middle ground between manual review and no guardrails. It targets high autonomy at low maintenance cost.

How it works:
- **Input layer**: A server-side prompt-injection probe scans tool outputs before they enter context, flagging suspicious content
- **Output layer**: A transcript classifier evaluates each action against decision criteria before execution

The classifier catches over-eager behavior (agent taking initiative beyond what user authorized), honest mistakes (misunderstood blast radius), prompt injection, and potential data exfiltration.

Results on internal data:
- False positive rate: 0.4% (action blocked unnecessarily)
- False negative rate on real overeager actions: 17% (dangerous actions that get through)

Auto mode is meant for tasks where manual approval overhead isn't worth the marginal safety — it catches enough dangerous actions to make autonomous operation substantially safer than no guardrails, but not a drop-in replacement for careful human review on high-stakes infrastructure.
