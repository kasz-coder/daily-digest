**Anthropic Engineering: Scaling Managed Agents — Decoupling the brain from the hands**

Anthropic published a deep dive on how they built Managed Agents—a hosted service that runs long-horizon agents through interfaces meant to outlast any particular implementation. The key insight: they decoupled what they think of as the "brain" (Claude and its harness) from both the "hands" (sandboxes and tools) and the "session" (the log of events). This follows the same pattern as operating systems virtualizing hardware into abstractions (process, file) general enough for programs that didn't exist yet.

Key technical points: In the old coupled design, any untrusted code Claude generated ran in the same container as credentials—so prompt injection only had to convince Claude to read its own environment. The structural fix: tokens are never reachable from the sandbox. They use two patterns—auth bundled with resources or held in a vault. For Git, they use each repo's access token during sandbox initialization and wire it into the local git remote, so push/pull work without the agent handling tokens.

Performance results: decoupling meant containers are only provisioned if needed. Sessions that don't need a container don't wait for one. Using this architecture, p50 TTFT dropped roughly 60% and p95 dropped over 90%.
