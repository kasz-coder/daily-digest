## OFFICIAL BLOGS

### Anthropic Engineering

**An update on recent Claude Code quality reports** — Anthropic traced user reports of degraded responses to three separate issues: 1) A change from high to medium default reasoning effort (reverted April 7); 2) A caching bug that cleared thinking history every turn instead of once, making Claude seem forgetful (fixed April 10); 3) A system prompt instruction to reduce verbosity that hurt coding quality (reverted April 20). All resolved as of v2.1.116. Key lesson: they need tighter controls on system prompt changes, broader eval suites for changes that trade off intelligence, and gradual rollouts. Usage limits have been reset for all subscribers.
[https://www.anthropic.com/engineering/april-23-postmortem](https://www.anthropic.com/engineering/april-23-postmortem)
