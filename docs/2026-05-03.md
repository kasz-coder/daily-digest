## Official Blogs

**Anthropic Engineering** — "An update on recent Claude Code quality reports"

Anthropic traced recent user reports of degraded Claude responses to three separate changes affecting Claude Code, the Claude Agent SDK, and Claude Cowork (the API was unaffected). All three issues have been resolved as of April 20. The first issue: on March 4, they changed Claude Code's default reasoning effort from high to medium to reduce latency, but this was the wrong tradeoff—they reverted on April 7 after users preferred higher intelligence. The second: a March 26 caching optimization intended to clear old thinking from idle sessions had a bug that kept clearing reasoning on every turn, making Claude seem forgetful and repetitive. This was fixed April 10. The third: an April 16 system prompt instruction to reduce verbosity (keep responses under 100 words) hurt coding quality and was reverted April 20. Anthropic is resetting usage limits for all subscribers and implementing tighter controls on system prompt changes.

[https://www.anthropic.com/engineering/april-23-postmortem](https://www.anthropic.com/engineering/april-23-postmortem)
