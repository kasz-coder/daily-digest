**Anthropic Engineering: Claude Code auto mode: a safer way to skip permissions**

Auto mode is a new middle ground between manual review and --dangerously-skip-permissions. It uses model-based classifiers to catch dangerous actions that aren't aligned with user intent, while letting everything else run without prompts.

The system has two layers: a prompt-injection probe at the input layer (screening tool outputs before they enter the agent's context), and a transcript classifier at the output layer that evaluates each action before execution. The classifier runs in two stages—a fast single-token filter for most actions, with chain-of-thought reasoning only if flagged.

Results on internal data show the full pipeline achieves 0.4% false positive rate ( benign actions blocked) and 17% false negative rate (dangerous actions let through). The false negatives are mostly cases where the classifier sees the danger but correctly identifies that user consent didn't cover the blast radius.

The defense targets four threat categories: overeager behavior, honest mistakes, prompt injection, and misaligned models. Auto mode is meant for autonomous operation where approval overhead isn't worth the marginal safety—not a drop-in replacement for careful human review on high-stakes infrastructure.

Key insights from the conversation: Waymo's approach treats full autonomy not as a single moonshot but as incremental progress—building safe systems first, then expanding capability. The 20 million rides aren't just a number; they're real-world evidence that the system works. Rather than pursuing theoretical perfect AI, Waymo focuses on making the current system safer and more capable through continuous engineering.
